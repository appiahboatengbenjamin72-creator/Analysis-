MT5 connection requirements

MetaTrader 5 does not expose its desktop terminal data directly to a GitHub Pages website. You need MT5 running on a computer/VPS plus a trusted bridge/API that serves HTTPS JSON and permits this site through CORS. The endpoint must accept symbol, timeframe and limit query parameters and return a JSON object with a candles array (or bars array), where each candle has time, open, high, low, close and optional volume. It may also return price, or bid and ask. Candle times may be milliseconds or Unix seconds. This app does not provide the server, authenticate to your broker, or independently verify the feed. Never put your MT5 password in this page or share it in chat.
